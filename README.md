# Penghitung Gaji Karyawan CLI

Sebuah program CLI interaktif untuk menghitung gaji karyawan berdasarkan jam kerja, upah lembur, dan potongan pajak.

## Fitur Utama

- Perhitungan gaji pokok harian.
- Perhitungan upah lembur otomatis (1.5x upah per jam).
- Perhitungan potongan pajak (5%).
- Laporan rincian gaji secara mendetail.
- Loop interaktif untuk menghitung gaji beberapa karyawan.

## Cara Penggunaan

Pastikan Anda sudah menginstal Python.

```bash
python src/main.py
```

Masukkan nama karyawan, jumlah jam kerja dalam satu hari, serta tarif per jam. Program akan menghitung gaji bulanan secara otomatis berdasarkan asumsi 30 hari kerja.

## Struktur Direktori

- `src/` : Berisi source code program.
